Description

Checking on character assign:-
- ft_isalpha
- ft_isdigit
- ft_isalnum
- ft_ascii
- ft_isprint

checking the length of character:-
- ft_strlen

To change the list of words to repepetive words:-
- ft_memset
- ft_bzero

to copy the source of memory to the destination:-
- ft_memcpy
- ft_memmove (incase of overlap)

to count the length of the words copies/catenates:-
- ft_strlcpy
- ft_strlcat

to change the words to uppercase or lowercase:-
- ft_toupper
- ft_tolower

to search the first word letter and print the rest:-
- ft_strchr
